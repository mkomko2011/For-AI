# JCP日報ルーティン用ツール

## name_resolver.py
日報の「作業指示者」などの自由記述（例：「玉井さん」「高橋新D」「【敦さん】」）から、社員の氏名・メール・役職を特定します。

- 参照元1：`①人事マスタ_INTS_FY27.xlsx`（シート「①社員マスタ」）…INTS在籍者。役職 M/SM/D/MD/役員 を管理職として扱う
- 参照元2：`社員証発行者リスト.xlsx` …INTLOOP全社（@intloop.com のアドレスのみ使用）
- 判定の順番：氏名一致 → 姓一致（INTSで一意 → INTSの管理職で一意 → 全社で一意）→ 名だけの一致（INTSで一意な場合のみ）
- 同じ姓の人が複数いて決まらない場合は「要確認」を返し、自動ではCCに入れない

人事データそのものはリポジトリに置かず、実行のたびにSharePointから最新版を読み込みます。
