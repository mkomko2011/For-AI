# INTLOOP/JCP パワーポイント作成ルール サマリー

## 元資料

- **JCPトレーニングマテリアル**（`JCPトレーニングマテリアル_元資料.pptx`）
- **INTSパワーポイントテンプレート ver2**（`INTSパワーポイントテンプレート_ver2.potx`）

---

## 1. 大原則（JCPマテリアル p.2）

1. シンプル・簡潔・分かりやすさを最優先する
2. 色はコーポレートカラーのみに絞る（色分けは凡例で意味を示す）
3. テキストは図形オブジェクト内に直接書き込み、図形とテキストを別々にしない
4. フォントは Meiryo UI に統一（本文）
5. 見出しのフォントサイズをスライド間で統一
6. メッセージのフォントサイズをスライド間で統一
7. 語尾を統一（「です/ます」または「である/だ」）
8. てにをは最適化、誤植なし

## 3. フォントサイズ（JCPマテリアル p.184, p.197）

| 用途 | pt |
|---|---|
| タイトル | 20（固定） |
| メッセージ | 18 |
| 大事 | 20 |
| 普通 | 16〜18 |
| 詳細 | 16 |
| 最低 | 14 |
| フッタ注釈 | 12 |

※2026/11 改定：本文系を元資料比+2pt（タイトルは据え置き）

---

## 4. メッセージ原則（JCPマテリアル p.96）

- 解釈を含める（「以下の通り」NG）
- タイトル・メッセージ・ボディが整合
- 3行以内
- 1文で完結（2文以上NG）

---

## 5. 配置原則（JCPマテリアル p.106〜）

- 左上→右下で配置
- 一方向展開
- パターン化チャート使用
- ガイド内収め
- 整列・等間隔・同サイズ・同色
