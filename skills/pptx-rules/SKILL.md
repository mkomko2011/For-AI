# pptx-rules スキル（INTLOOP／JCP 準拠）

## 目的

INTLOOPのコーポレートブランド（INTS PowerPointテンプレート）と、JCPトレーニングマテリアルの
大原則・デザイン原則・文章原則に100%準拠したスライドを、毎回ブレずに作成する。

---

## 起動条件（MUST）

以下のいずれかのフレーズが検出された場合、**本スキルを必ず最初にロード**する：

- 「パワポ」「PowerPoint」「.pptx」「スライド」「デック」「プレゼン」
- 「資料作って」「提案書」「報告書（スライド形式）」
- 既存の.pptxに対する編集・レビュー依頼

---

## 処理フロー（5ステップ）

### Step 1: ルール読込

本SKILL.mdを全文読み、以降の作成・検証で**絶対に逸脱しない**ことを宣言してから作業開始。

### Step 2: テンプレート読込

必ず `reference/INTSパワーポイントテンプレート_ver2.potx` をベースに作成する。
テンプレートのマスタースライド・カラー・フォントをそのまま継承。

### Step 3: スライド作成

後述の【大原則】【デザインルール】【文章ルール】【図解ルール】に沿ってスライドを構築。
`python-pptx` を用いる場合のサンプルコードは `scripts/` 参照。

### Step 4: 自動検証

作成完了後、**必ず**以下を実行：

```bash
python3 scripts/check_compliance.py --input "<作成したpptxのパス>"
```

違反が検出されたら、**そのスライドを修正**してから納品。警告のみの場合はユーザーに通知して判断を仰ぐ。

### Step 5: 納品

- 出力ファイルを `/mnt/outputs/` に保存
- ファイルパスを `computer://` リンクでユーザーに提示
- 準拠レポート（違反0件 or 修正済み）をテキストで報告

## 【大原則】（JCPトレーニングマテリアル p.2）

| No. | 原則 | チェック観点 |
|---|---|---|
| 1 | シンプル・簡潔・分かりやすさ最優先 | 1スライド1メッセージ、冗長表現禁止 |
| 2 | **色はコーポレートカラーのみ**に絞る | 色分けする場合は凡例で意味を示す |
| 3 | **テキストは図形オブジェクト内に直接書き込む**。図形とテキストを別オブジェクトにしない | 独立テキストボックス検出で自動違反 |
| 4 | フォントは全テキスト **Meiryo UI** に統一 | 見出し・本文・注釈すべて |
| 5 | **見出し**フォントサイズをスライド間で統一 | |
| 6 | **メッセージ**フォントサイズをスライド間で統一 | |
| 7 | スライド内の**語尾を統一**（「です/ます調」 or 「である/だ調」） | 混在禁止 |
| 8 | てにをは最適化、誤植なし、読みやすい日本語 | |

## 【デザインルール】

### カラーパレット（INTS theme1.xml 抽出済み・絶対準拠）

| 役割 | カラー | 用途 |
|---|---|---|
| Text | #000000 | 本文・見出し |
| Background | #FFFFFF | 背景 |
| **Corporate Navy** | **#033865** | 最重要強調・表紙帯 |
| Gray | #7F7F7F | 補足・低優先度 |
| Accent1 (Bright Blue) | #0099CC | メインアクセント |
| Accent2 (Blue) | #0087C5 | セカンダリ |
| Accent3 (Purple-Blue) | #6666FF | 補助 |
| Accent4 (Red) | #C00000 | 強調・ネガティブ・減少 |
| Accent5 (Orange) | #FF9900 | 補助 |
| Accent6 (Yellow-Orange) | #FFC000 | 補助 |

**これ以外の色は使用禁止**（許容誤差 ±5 per channel）。同系統の濃淡で表現する。

### 色の一般意味（p.195）

- 青系：ポジティブ／減少／安定
- 赤系：ネガティブ／増加／強調
- この意味に反する色使いは禁止

### フォントサイズ階層（p.184, p.197）

| 要素 | サイズ |
|---|---|
| タイトル（見出し） | 20pt（固定・後述） |
| メッセージ（リード文） | 18pt |
| 最重要本文 | 20pt |
| 普通本文 | 16pt（推奨） / 18pt |
| 詳細・表 | 16pt |
| **最低サイズ** | **14pt** |
| フッタ注釈 | 12pt |

※2026/11 改定：本文系の標準サイズを従来比+2pt に引き上げた（タイトル20ptは据え置き）。

**禁止**：入りきらないから1つだけフォントを下げる → 図形拡大 or 全体ダウンで対応。

### 線スタイル（p.184）

| 用途 | 太さ |
|---|---|
| 普通 | 0.5pt |
| ハイライト | 2.25pt |
| 罫線 | 0.5pt 点線・グレー |

### 強調ルール（p.185-188）

1. 強調は**最重要部分のみ**に限定
2. 強調手段を併用しない（色/太字/下線/斜字を混在させない）
3. 使用色は**1色 or 同系統の濃淡**のみ
4. 全て太字は「何も強調していない」に等しい（禁止）

### タイトル下の装飾線について（AI生成スライドの典型悪癖）

タイトル直下の装飾ラインは**使用禁止**。余白または背景色で区切る。

### タイトル（見出し）テキストのスタイル規則（INTS固有ルール）

コンテンツスライドのタイトルプレースホルダー（idx=0）には、以下を**必ず適用**する：

| 項目 | 設定値 |
|---|---|
| フォント | Meiryo UI |
| **フォントサイズ** | **20pt** |
| **文字色** | **#000000（黒）** |
| 太字 | True |
| **影（Shadow）** | **なし（False）** |
| 文字揃え | 左揃え |

**禁止**：タイトルに白色（#FFFFFF）・影・装飾を適用すること。  
**理由**：テンプレートのマスター背景によっては白文字が視認不能になるため。

`python-pptx` での実装例：
```python
# タイトルプレースホルダー（idx=0）設定
run.font.name  = "Meiryo UI"
run.font.size  = Pt(20)
run.font.bold  = True
run.font.color.rgb = RGBColor(0x00, 0x00, 0x00)  # 黒・必須
# 影を明示的に除去（テンプレート継承分を含む）
from pptx.oxml.ns import qn
for eff in run._r.findall('.//' + qn('a:effectLst')):
    eff.getparent().remove(eff)
```

### ページ番号（INTS固有ルール・必須）

**表紙（1枚目）以外のすべてのスライドにページ番号を必ず挿入する**（Appendix・免責事項・著作権スライドを含む）。

- テンプレートのレイアウトにある**スライド番号プレースホルダー（`type="sldNum"`）をスライドに複製**して使う。数字を手入力したテキストは禁止。
- `python-pptx` の `add_slide()` はスライド番号プレースホルダーを自動では作らないため、必ず明示的に追加する。

```python
import copy
from pptx.oxml.ns import qn

def add_slide_number(slide):
    tree = slide.shapes._spTree
    if any(ph.get("type") == "sldNum" for ph in tree.iter(qn("p:ph"))):
        return
    for sp in slide.slide_layout.shapes._spTree.iter(qn("p:sp")):
        ph = sp.find(".//" + qn("p:ph"))
        if ph is not None and ph.get("type") == "sldNum":
            new = copy.deepcopy(sp)
            new.find(".//" + qn("p:cNvPr")).set("id", str(900 + len(slide.shapes)))
            tree.append(new)
            return

for i, s in enumerate(prs.slides):
    if i > 0:            # 表紙以外
        add_slide_number(s)
```

### 箇条書き（行頭文字とぶら下げインデント・必須）

箇条書きは**PowerPointの箇条書き機能（行頭文字）**で設定する。「・」「•」「■」等を**文字として入力することは禁止**。

| 項目 | 設定値 |
|---|---|
| 行頭文字 | 標準の小さい丸「•」（U+2022、行頭文字フォント Arial）※PowerPointの箇条書きギャラリーの「•」 |
| 左インデント（marL） | 228600 EMU（0.635cm） |
| ぶら下げ（indent） | -228600 EMU（marL と同値のマイナス） |
| 折り返し | 2行目以降は行頭文字の分だけ下げ、1行目の本文の頭にそろえる（上記設定で自動的にそろう） |

```python
from pptx.oxml.ns import qn

def make_bullet(p, char="\u2022", mar=228600, bu_font="Arial"):
    pPr = p._p.get_or_add_pPr()
    pPr.set("marL", str(mar))
    pPr.set("indent", str(-mar))          # ぶら下げインデント
    for tag in ("a:buNone", "a:buChar", "a:buAutoNum", "a:buFont"):
        for el in pPr.findall(qn(tag)):
            pPr.remove(el)
    pPr.append(pPr.makeelement(qn("a:buFont"), {"typeface": bu_font}))
    pPr.append(pPr.makeelement(qn("a:buChar"), {"char": char}))
```

- 行間を取る場合は `p.space_after = Pt(6)` を**行頭文字の設定より先に**指定する（pPr の子要素順序のため）。
- ①②…の番号付き項目は行頭文字を付けない（二重記号の禁止）。

## 【文章ルール】

### メッセージ原則（p.87-96）

1. **1スライド1メッセージ**（複数メッセージ禁止）
2. メッセージは**3行以内**
3. メッセージは**1文**で完結（2文以上禁止）
4. 「**以下の通り**」「詳細は下記」等の解釈委ね表現は禁止
5. メッセージには必ず**解釈（So What?）**を含める。事実の羅列は禁止
6. 解釈の4類型：
   - ポジティブ（良い・多い・大きい）
   - ネガティブ（悪い・少ない・小さい）
   - 最小値（最小でもXX以上）
   - 最大値（最大でもXX以下）
7. タイトル・メッセージ・ボディが論理整合していること
8. ピラミッドストラクチャー（So What? / Why So?）を維持

### 語尾統一

- パッケージ内で「です/ます調」か「である/だ調」のどちらかに統一
- **デフォルトは「である/だ調」**（戦略コンサルティング資料の慣例）
- ユーザーが別途指定した場合はそれに従う

### 表記統一

- カタカナ・英数字の**全半角をパッケージ内で統一**（推奨：全角カタカナ、半角英数字）
- 誤植・てにをは違和感ゼロ

## 【図解・配置ルール】（p.106-197）

### 配置の基本

1. 視線は**左上→右下**で配置
2. 展開方向は**縦横どちらか一方向**に統一
3. パターン化されたチャートから選択（ツリー/ステップ/インフルエンスダイアグラム/
   評価テーブル/マトリックス/ロードマップ/フロー/分岐図/ビジネスモデル/ピラミッド/レイヤー）

### 図形ルール

1. 図形はガイドライン内に収める（はみ出し禁止）
2. 図形は整列（上下・左右揃え）
3. 並列図形は等間隔、意味が異なる図形は間隔をあける
4. 並列図形は同サイズ
5. 並列図形は同色

### テキストと図形（最重要）

**テキストは必ず図形オブジェクト内にテキストとして埋め込む**。
- ❌ 図形のみ配置して、その上に独立テキストボックスを重ねる
- ✅ 図形のテキストプロパティに直接文字を入れる

`python-pptx` では `shape.text_frame.text = "..."` で図形内テキストとして扱う。
独立した `Textbox` を図形の上に重ねて配置するパターンを検出器でNGとする。

### 文字揃え（p.196）

| 要素 | 揃え |
|---|---|
| カテゴリ（見出し） | 中央揃え |
| 数値 | 右揃え |
| 文字 | 左揃え |

## 【スライド構成要素】（p.85）

各スライドは以下の要素で構成する：

1. （ナビゲーター）：現在位置を示すインジケータ（任意）
2. **タイトル**：スライドの主題
3. **メッセージ**：1文の結論（必須）
4. **ボディ**：1つ以上のパネル
5. **フットノート**：出典・注釈（12pt）

### パッケージ構成テンプレ

表紙 → 目次 → 前提／背景 → 主張 → 根拠 → まとめ → Appendix

## 【自動検証（scripts/check_compliance.py）】

作成完了後、必ず実行する。以下の12観点をチェックする：

| # | チェック項目 | 判定 |
|---|---|---|
| 1 | 非Meiryo UIフォントの使用 | エラー |
| 2 | ブランドカラー外の色使用 | エラー |
| 3 | 独立テキストボックス（図形と分離） | エラー |
| 4 | タイトルフォントサイズのスライド間不一致 | 警告 |
| 5 | メッセージフォントサイズのスライド間不一致 | 警告 |
| 6 | 14pt未満のフォント | エラー |
| 7 | 語尾の混在（です/ます と である/だ） | 警告 |
| 8 | 禁止表現（「以下の通り」「詳細は下記」等） | エラー |
| 9 | メッセージが3行超 | エラー |
| 10 | 1スライドに複数メッセージ領域の疑い | 警告 |
| 11 | 表紙以外のスライドにページ番号（スライド番号プレースホルダー）がない | エラー |
| 12 | 行頭記号（・•●■◆- 等）を文字で入力している（箇条書き機能を使っていない） | エラー |

**合格条件**：エラー0件。警告が出た場合はユーザーに内容を報告し判断を仰ぐ。

## 【禁止事項まとめ】

1. Meiryo UI以外のフォント
2. ブランドカラー外の色
3. 独立テキストボックス（図形とテキストの分離）
4. 1スライドに複数メッセージ
5. メッセージ3行超
6. メッセージ2文以上
7. 「以下の通り」「詳細は下記」等の解釈委ね表現
8. 14pt未満のフォント
9. 語尾混在
10. 強調手段の併用（色・太字・下線・斜字の混用）
11. タイトル直下の装飾線
12. 図形のガイドライン逸脱
13. 並列図形のサイズ・色・間隔不統一
14. タイトルテキストへの白色・影・装飾の適用（黒・20pt・影なし が必須）
15. 表紙以外のスライドでのページ番号の欠落
16. 行頭記号の文字入力（箇条書き機能＋ぶら下げインデントを使うこと）
