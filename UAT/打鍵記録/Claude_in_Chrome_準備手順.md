# Claude in Chrome 準備手順（UAT 打鍵代行用）

## 現状（2026-11-18 確認）

- このクラウドセッションには Claude in Chrome のツールが接続されていない。
- PC1954 の Remote Control フォルダ（UAT作業 など）は一覧にあるが「クラウドセッションからは利用不可」の状態。
- クラウド環境から https://ints-talent.vercel.app へは到達できる（ログイン画面の取得のみ実施）。ただしログイン（パスワード入力）はしないルールのため、ログイン後の画面はこの環境からは確認できない。

→ **小出さんの PC の Chrome（ログイン済み）を Claude に操作させる構成が必要。**

## 手順（PC1954 側）

1. Chrome に拡張機能「Claude in Chrome」を入れる（Chrome ウェブストアで「Claude」を検索。Anthropic 提供のもの）。拡張機能のアイコンから、この Claude と同じアカウントでサインインする。
2. Claude を PC 上で動かす（どちらか）:
   - Claude デスクトップアプリの Claude Code で、作業フォルダ（例: UAT作業）を開いてセッションを開始する
   - またはターミナルで作業フォルダに移動し、Chrome 連携を有効にして Claude Code を起動する（`claude --chrome`、起動後なら `/chrome` で接続状態を確認・有効化）
3. 作業フォルダにこのリポジトリの UAT フォルダ（支援パック・本記録）を置く（`git clone` してブランチ claude/practical-franklin-nplu4t を取得、または ZIP で取得）。
4. Chrome で https://ints-talent.vercel.app に**ご自身で**ログインしておく（Claude はパスワードを入力しない）。
5. 新しいセッションで次のように依頼する:
   「UAT/打鍵記録/Talent_P0_TM-001-003_実行記録.md の観点で TM-001〜003 を Claude in Chrome で実行し、スクリーンショットと判定案を同じフォルダに保存して。ルールは記録ファイル冒頭のとおり」

## クラウドセッションから PC を使いたい場合（任意）

- PC1954 の Claude アプリを最新版に更新し、Remote Control で共有するフォルダがホーム直下の隠しフォルダや ~/Library 配下でないことを確認する（設定 › Claude Code › Remote Control）。
- ただし、クラウドから PC フォルダを使う機能は全アカウントに提供済みではない。確実なのは上の「PC 上で Claude を動かす」方法。

## 実行時のルール（再掲）

1. 本番 URL・共有 DB。他の人が打鍵している時間は動かさない
2. 03:00 前後（Talent↔Review 自動同期）は実行しない
3. 「初期データを再投入」は小出さんの指示があるときだけ
4. パスワードは入力しない。ログインが切れたら止めて報告
5. 結果（OK/NG/保留の案）・スクリーンショット・NG 起票文案を UAT/打鍵記録 に保存。確定は人が行う
